## Как использовать

- Переносить композиционные принципы, а не чужие бренды и точную архитектуру.
- Цель Muscat: 1000 машин, два этажа CityWalk, реечный навес с сезонным распылением. Фото не доказывают вместимость, бюджет или тепловую эффективность.
- Официальные фото без подтверждённой лицензии остаются внешними ссылками. Атрибуция не даёт права копировать их в публичные assets. Dream Island прямо требует письменное согласие правообладателя.
- У трёх фотографий Wikimedia Commons проверены конкретные CC-лицензии, авторы и условия. Ещё один дорожный вид имеет Unsplash License. Единой открытой лицензии на все изображения нет.
- HTML использует внешние изображения;при отсутствии интернета остаются подписи и ссылки. Локальные скриншоты визуальной проверки исключены изGit через .gitignore.
